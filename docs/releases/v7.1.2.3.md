# v7.1.2.3

Release date: 2026-11-03.

## Preserve native timestamps

The normalized event date is validated and supplied as external_created_at.
Chatvand can show late/recovered messages in source order without rewriting
database insertion time, unread tracking or audit timestamps. Milliseconds are
normalized; malformed, implausibly old and future values are ignored.
File: chatwoot_bridge.py. No database migration.

## Delete the correct part of an attachment batch

A native deletion resolves its batch parent and attachment/text part instead
of deleting live siblings. A whole Chatvand deletion walks every confirmed
native sibling, checkpoints successes and ignores native partial-delete echoes.
Files: chatwoot_bridge.py, ChatwootClient.delete_message_part and batch-delete
regressions. Requires the companion Chatvand partial-deletion endpoint.

## Isolate Eitaa revocations and unblock deleted media

Account-wide deletes are associated with one peer using same-instance mappings
and retained originals. Ambiguities and channel recovery errors stay isolated.
A later verified revocation durably supersedes an undelivered original, keeping
its snapshot until settlement so an unavailable deleted file cannot deadlock
that chat. Files: polling.py and test_inbound_event_retry.py.

## Apply conversation policy to verified native identity

Conversation lookup includes the canonical contact and independently verified
aliases in the same instance/account scope. Historical outbound callbacks do
not steal the active inbound route. The authenticated conversation-policy
preflight verifies the configured account/inbox and existing channel HMAC token,
then returns canonical contacts and the live reopen policy before Chatvand
creates a ticket. New recipients require independently verified platform phones.
Scoped consolidation redirects preserve old callback IDs and existing native
send receipts. Settings normalization retains and validates these redirects;
retired contacts are excluded from new remote lookups. No WhatsApp identifier
is written or replaced. No schema migration.
Files: chatwoot_bridge.py, conversation_mapping.py, instances/service.py,
_handler_controller.py, contact alias tests and the API route contract.
